@NAME@ - run the performance tests (cpu, mem, disk, nvme, pg, net, web, sustain, burn-in) on this machine and collect the results.

  @CMD@                       # cpu, mem, disk; results in ~/bench-results/<label>-<time>/
  @CMD@ --with web,pg         # the default stages plus web and pg
  @CMD@ --only disk           # only these stages
  @CMD@ --with net --peer 192.0.2.10
  @CMD@ --rounds 5            # cpu, mem and web repeat 5 times instead of 3
  @CMD@ --detach              # start in a tmux session and return; follow with: vmbench status
  @CMD@ --only burnin --hours 48
  NVME_DEVS="nvme1n1 nvme2n1" CONFIRM_WIPE=yes @CMD@ --only nvme     # bare metal: every NVMe at once, then each (ERASES them)
  @CMD@ --only sustain        # 30 min all-core load: clock, temperature, power (turbostat, ipmitool as root)
  QUICK=1 @CMD@               # smoke run: tiny sizes and durations, to check the setup

Options:
  --with LIST   add stages to the default ones (comma separated)
  --only LIST   run only these stages (cannot be combined with --with)
  --peer HOST   peer machine for the net stage; it must run: iperf3 -s -D ; sockperf server -i 0.0.0.0 &
  --hours N     length of the burn-in (default: 48; QUICK=1 always runs 40 seconds)
  --rounds N    repeats of cpu, mem and web (default 3; QUICK=1: 1); every round is one row per value in results.tsv
  --disk-rounds N  repeats of the disk stage (default 1, each extra round is about 20 min, see docs/tests.md)
  --detach      after the pre-flight passes, run inside a new tmux session and return at once
  --session NAME  name of that tmux session (default: vmbench-<label>)
  --list        show the stages, their duration and whether this machine is ready for them
  --metrics     print the table of metric ids (id|unit|direction|tool|label|what it measures) and exit
  -h, --help    show this text

Stages (ram is accepted for mem). info always runs, because report.py needs it.
@STAGES@
Every result has a stable id such as cpu.sysbench.prime.1t, listed by --metrics and in docs/tests.md.

Every selected stage is checked before anything runs. If something is missing, the script lists all of it
and exits with code 2. A run of everything that needs no peer is: --with web,pg  (add net when a peer is available)

Settings (environment variables):
  STAGES       space separated stage list, ignored when --with or --only is given
  LABEL        name of this machine in the results           (default: hostname)
  OUT          result folder                                 (default: ~/bench-results/<label>-<time>)
  ROUNDS       repeats of cpu, mem and web                   (default: 3)
  MEM_ROUNDS WEB_ROUNDS  repeats of one of them                (default: ROUNDS)
  DISK_ROUNDS  repeats of the disk stage                     (default: 1)
  PG_ROUNDS    repeats of the pg measurements (data loaded once) (default: 1)
  PG_SCALE     pgbench scale factor                          (default: data of 1.5 x RAM, capped by free space)
  QUICK        1 = short smoke run                           (default: 0)
  CB           cpubench folder (setup-cpubench.sh output)    (default: ~/cpubench-current)
  DATA_DIR     folder for fio test files                     (default: ~/bench-data)
  FIO_SIZE     size of the fio test file                     (default: 8G)
  RAW_DEV      raw test disk, e.g. /dev/sdb (needs CONFIRM_WIPE=yes, ERASES THE WHOLE DISK)
  NVME_DEVS    disks of the nvme stage (and burnin), e.g. "nvme1n1 nvme2n1" (needs CONFIRM_WIPE=yes, ERASES THEM ALL;
               never the OS disk: a disk with a filesystem, mount or partitions is refused)
  SUSTAIN_MINUTES SUSTAIN_50_MINUTES  full-load and 50%-load minutes of the sustain stage (default: 30, 15)
  TJMAX        Tjmax in C for the thermal headroom, when turbostat does not print it (AMD, ARM)
  DB_DIR WAL_DIR  folders for disk.fio.db-* and disk.wal.*           (default: DATA_DIR; e.g. /pgdata /pgwal)
  PGPORT PGHOST PGDATABASE  PostgreSQL to use for the pg stage (default: port 5433, db bench, from setup-postgres-bench.sh)
  XLSX         1 = also write review.xlsx (vmbench report xlsx) at the end; needs python3-openpyxl (default: 0)
  XLSX_LAYOUT  layout.tsv for review.xlsx (see vmbench report layout); implies XLSX=1
  PEER         same as --peer
  BURNIN_HOURS same as --hours
